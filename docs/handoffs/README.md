# Work handoffs

Create a handoff when unfinished work must continue in another session or on another device.
Use `YYYY-MM-DD-short-task.md`. Prefer the existing issue for task status; link it rather than duplicating a backlog.

## Required fields

- Status: active, completed, blocked, or superseded; include the date.
- Goal, scope, and relevant issue or plan.
- Repository, branch, and last relevant commit.
- Completed changes and any uncommitted work that still needs transfer.
- Checks run, results, and unverified behavior.
- Decisions made, with links to accepted records.
- Blockers, next concrete action, and required platform or local data.
- Links to relevant source and documentation.

Commit approved work and the handoff before switching devices when Git policy permits.
Uncommitted changes do not transfer through Git; state that limitation explicitly.
Keep credentials, private records, and full transcripts out of handoffs.
Mark completed or superseded handoffs so later sessions do not resume obsolete work.
